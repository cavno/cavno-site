第一步：检查并还原 macOS 系统的键盘底层设置

（目的：确保 Mac 没有在底层把你的物理按键调换，如果之前没改过也建议看一眼确认）

  1. 点击屏幕左上角苹果图标 -> 选择 系统设置 (System Settings)。
  2. 在左侧边栏往下滑，找到并点击 键盘 (Keyboard)。
  3. 在右侧页面中，点击 键盘快捷键... (Keyboard Shortcuts...) 按钮（会弹出一个新窗口）。
  4. 在弹出窗口的左侧边栏最下方，点击 修饰键 (Modifier Keys)。
  5. 在右侧顶部的 选择键盘 (Select keyboard) 下拉菜单中，点选你外接的那把 Windows 物理键盘名称（不要选成内置或其他虚拟设备）。
  6. 确认下面几项的对应关系完全一致（如果不一致，点击右侧下拉框改回来，或者直接点右下角的 恢复成默认值）：
    • 大写锁定 (⇪) 键 -> ⇪ 大写锁定
    • Control (^) 键 -> ^ Control
    • Option (⌥) 键 -> ⌥ Option
    • Command (⌘) 键 -> ⌘ Command
  7. 点击右下角 完成 (Done)，关闭 macOS 系统设置。

第二步：清空 Parallels 的“画蛇添足”键位转换

（目的：Parallels 默认会把你的物理 Win 键转成 Ctrl，把这一步关掉才能让 Ctrl 归 Ctrl、Win 归 Win）

  1. 先打开 Parallels Desktop 软件。将鼠标移到屏幕最顶部菜单栏，点击右上角（时间、Wi-Fi 图标附近）的 Parallels 图标 ||（两条竖线）。
    • 注：如果你的 Win11 处于全屏模式看不到顶部菜单栏，请把鼠标移到屏幕最顶端停留 1 秒，菜单栏就会自动滑下来；或者按 Control + Alt (物理键) 释放鼠标后再移到顶部。
  2. 在弹出的下拉菜单中，点击 偏好设置... (Preferences... / Settings...)。
  3. 在弹出的窗口顶部，点击第二个标签页：快捷键 (Shortcuts)。
  4. 在窗口左侧列表中，点击选中你的虚拟机名称（通常叫 Windows 11）。
  5. 看窗口右侧区域：
    • 你会看到一排长长的列表（比如 ⌘ + C -> Ctrl + C、⌘ + V -> Ctrl + V、⌘ -> Win 等），前面都有打勾 ☑。
    • 操作方法 A（最快）：点击右上角 配置文件 (Profile) 下拉框（当前一般显示为“Windows”），查看是否有 通用 (Generic) 或空白配置；如果没有，直接用方法 B。
    • 操作方法 B（最彻底）：把右侧列表里所有打勾 ☑ 的项目全部点击取消勾选 ☐（重点一定要取消 ⌘ -> Ctrl 相关的所有映射，以及单按 ⌘ -> Win 的映射）。
    • 原理说明：全部取消后，Parallels 就不再篡改按键，你的物理 Ctrl 就会原封不动地作为 Ctrl 传给 Win11，物理 Win 键也会原封不动地作为 Win 键传给 Win11。

第三步：让 Win11 独占所有系统级组合键

（目的：防止你在 Win11 里按 Win + Space 切输入法或按 Alt + Tab 切窗口时，弹出 Mac 的搜索框）

  1. 保持在刚才的 Parallels 偏好设置 -> 快捷键 (Shortcuts) 窗口不要关。
  2. 在窗口左侧列表的下方，点击 macOS 系统快捷键 (macOS System Shortcuts)。
  3. 在右侧找到 发送 macOS 系统快捷键 (Send macOS system shortcuts) 下拉菜单。
  4. 点击下拉菜单，将其改为 始终 (Always)。
  5. 直接关闭这个“偏好设置”窗口即可（修改会自动保存）。

第四步：开启键盘底层硬件直通（消除按键粘滞与冲突）

（目的：确保 Ctrl + Shift + Esc、Win + V、Alt + F4 等多键组合灵敏无延迟）

  1. 再次点击屏幕顶部菜单栏右上角的 Parallels 图标 || -> 点击 控制中心 (Control Center)。
  2. 在控制中心里找到你的 Windows 11 一行，点击右侧的 齿轮图标 ⚙️（设置），打开这台虚拟机的专属配置 (Configuration) 窗口。
  3. 在弹出窗口的顶部标签栏，点击 硬件 (Hardware)。
  4. 在左侧边栏中，点击 鼠标与键盘 (Mouse & Keyboard)。
  5. 在右侧找到 键盘 (Keyboard) 下拉菜单：
    • 将默认的“针对系统快捷键自动优化”改为 针对游戏进行优化 (Optimize for games)。

第五步：关闭 Mac 与 Win11 的输入法互相干扰

（目的：避免在 Win11 里按 Shift 切换中英文时，被 Mac 系统的输入法状态强行拉回去）

  1. 保持在刚才的第 4 步 虚拟机配置 (Configuration) 窗口不要关。
  2. 点击窗口顶部标签栏的 选项 (Options)。
  3. 在左侧边栏中，点击 更多选项 (More Options)。
  4. 在右侧找到 键盘：同步键盘布局 (Synchronize keyboard layout) 这一项：
    • 取消勾选 ☐（如果它是个下拉菜单，选择“不切换 / 关闭”）。
  5. 关闭配置窗口。

第六步：10 秒钟现场验收测试

现在点进你的 Windows 11 窗口（建议点击左上角绿色全屏按钮进入全屏模式），按顺序按下你物理键盘左下角的三个键进行验证：

  1. 测试物理 Win 键（左下角第 2 个键）：
    • 单独按一下 Win 键：Win11 的开始菜单应该立即弹出来。
    • 按 Win + E：应该弹出 Windows 文件资源管理器。
    • 按 Win + D：应该直接显示 Windows 桌面。
  2. 测试物理 Ctrl 键（左下角第 1 个键）：
    • 随便选中一个桌面图标或文字，按 Ctrl + C 和 Ctrl + V：正常复制粘贴。
    • 按 Ctrl + Shift + Esc：直接弹出 Windows 任务管理器。
  3. 测试物理 Alt 键（左下角第 3 个键）：
    • 打开两个窗口，按 Alt + Tab：在 Windows 内部丝滑切换窗口，不会跳回 Mac。
    • 按 Alt + F4：正常关闭当前 Windows 窗口。

附：日常使用小贴士（鼠标如何切回 Mac？）

因为开启了全套直通和快捷键接管，当你全屏在 Win11 里工作时，所有按键都会留在 Win11 内部。如果你偶尔需要跳回 Mac 桌面：

  • 方法 1（鼠标滑出）：把鼠标指针推到屏幕最顶端边缘并停顿 1 秒，macOS 的顶部菜单栏或程序坞就会浮现出来。
  • 方法 2（释放快捷键）：同时按下物理键盘的 Ctrl + Alt，即可把鼠标和键盘焦点暂时交还给 macOS。

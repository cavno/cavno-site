§ 01 — 干净的住宅 IP

家庭宽带级，从没被干过坏事

想象在美国申请了一条普通家庭宽带 —— 没有被人拿去刷过号、没有跑过爬虫、ASN 归属是真正的家用 ISP。 这就叫干净的住宅 IP。Anthropic 看到这种 IP，会默认你是个普通用户，注册时甚至不会要手机短信验证。

判断标准

注册 Anthropic 不弹手机验证

用这个 IP 去 console.anthropic.com 注册账号 —— 如果不要求短信验证码，这个 IP 就是干净的。要短信 = 已经被风控盯上，再用也没用。

自查：打开 ipinfo.io 或 ip-api.com，看 proxy / hosting 字段是不是都 false。

推荐选项

真家用 ISP 段的网络出口

挑选美国家用网络服务时，看上游 ASN：NeoFiber、Springtide、Comcast、Verizon、Spectrum 这类家庭宽带 ISP 才是真住宅段。同一段地址、同一个 ISP 字段，质量稳定。

实测合格：专业服务商的家用线路里，挑选 ip-api 字段 proxy=false 的节点；同一节点用半年没被封。

避开

机房 IP 和"假家用"线路

  • 机房 ASN：AWS / GCP / Azure / 阿里云 / DigitalOcean — Anthropic WAF 直接拒
  • 中转转发：ip-api 显示 org=...Technology 这种名字的，大概率不是终端家用
  • 公司远程网络：商业级远程网络出口大多落在机房
§ 02 — 干净的指纹浏览器

一个账号绑死一台"虚拟电脑"

指纹浏览器是一个模拟出来的固定环境 —— 屏幕分辨率、字体、时区、Canvas、WebGL、WebRTC 全部固定。 无论你在 Mac、Windows、还是别人家的电脑上打开它，Anthropic 永远看到的是同一台机器。 这是"我一直在用同一台电脑"的最低成本实现。

判断标准

跨物理机登录指纹不变

同一个 Claude 账号，无论你今天用 MacBook 还是公司 Windows，只要打开这个虚拟环境登录，Anthropic 看到的所有特征都一致。

验证：访问 browserleaks.com，两台电脑跑出来的 fingerprint 必须完全一致。

推荐选项

AdsPower

市场上做得最稳的指纹浏览器之一。每个账号分配独立环境 + 独立美国家用网络出口，所有动作（登录、付款、OAuth 授权）都在这一个环境里完成。

  • WebRTC 设 Replace（不是 Disable）
  • 固定时区为网络出口对应的美国时区
  • 账号、环境、网络出口 1 : 1 : 1 绑死
避开

裸 Chrome 和共用环境

  • 原生 Chrome 直接登 —— 设备指纹漂移，登一次掉一次"信任"
  • WebRTC = Disable —— 全网都开你独家关 = 异常
  • 多账号共用同一环境 —— 任一账号出问题，整窝连坐
§ 03 — 干净的域名邮箱

买个域名，像一家小公司

Anthropic 对邮箱的判断逻辑是：自有域名邮箱（你@你的公司.com）= 大概率是个有自己业务的小公司； Gmail / Apple ID OAuth = 个人用户，且 Google 那边一旦有任何账号出过事，全网账号都会被"关联连坐"。

判断标准

自有域名、catch-all、可收码

  • 是自己买的域名，不是公共邮箱后缀
  • 支持 catch-all（任意前缀@你的域名 都能收到）
  • 用这个邮箱注册 Anthropic 时不弹手机验证
推荐选项

Porkbun + Cloudflare Email Routing

  • 在 Porkbun 买一个普通 .com 域名（避开 .xyz / .top 等高风险后缀）
  • 接入 Cloudflare，开 Email Routing
  • 配置 catch-all 转发到你的主邮箱 / 自建收件箱

成本：约 $10 / 年域名费 + Cloudflare 免费。

避开

Google / Apple / Outlook

  • Gmail / Google OAuth —— Google 有完整设备 + 信用卡 + 恢复邮箱链路，任一关联出事就连坐
  • Apple ID 注册 —— 实测会被 Anthropic 拒（"cannot be created at this time"）
  • Outlook —— 注册时直接弹手机验证，已不干净
  • 自己旧域名 —— 以前公开使用过的域名可能整个域已被打标
§ 04 — 干净的 3DS 银行卡

真实银行账户，最好是公司卡

Claude Pro / Max 订阅是用 Stripe 收款。Stripe 会查 BIN（卡头）识别这张卡是真实银行还是虚拟卡， 会查 3DS 验证能力，会查这张卡有没有正常使用记录。 一张干净的卡 = 一张"看上去就是真有人在用"的卡。

判断标准

真账户 + 3DS + 在用

  • 是真实银行账户（不是 E-money）
  • 支持 3DS 二次验证
  • 有正常流水，不透支不冻结
  • BIN 来自正常发卡行（不是新虚拟卡 BIN 段）
推荐选项

Mercury（美国公司卡）

首选：自己美国公司开的 Mercury 账户卡。真实 ABA 路由号、FDIC 保险、Stripe 100% 兼容、在硅谷圈被视为"正统"。EIN 拿到当天就能申请，1–3 个工作日开通。

关键画像：有公司日常运营流水 + 3DS + 真实银行账户 —— 在 Stripe 风控眼里就是"放心客户"。

避开

电子钱包卡和异常卡

  • 各类电子钱包发行卡 —— BIN 段一查就不是真银行，Stripe 直接拒
  • Wise Business 当主卡 —— E-money 不是真银行账户，UBO 审核会卡
  • 学生卡 / 长期空账 / 透支过的卡 —— 异常使用记录
REALITY CHECK

所谓"养号 / 关遥测",
都是安慰剂。

— 01
养号没用
什么"先用一个月再升级"、"先聊天一周再付费" —— Anthropic 根本不看这个。看的是身份基线是否干净。
— 02
关闭遥测无关
CC 客户端那点 telemetry 不是封号依据。封号依据是 IP / 设备指纹 / 邮箱 / 支付 组成的身份画像。
— 03
缺一个就是时间问题
四个干净是一套，少一个用着用着就会被封。15 个号的封禁规律 100% 落在缺失项上 —— 不是运气。

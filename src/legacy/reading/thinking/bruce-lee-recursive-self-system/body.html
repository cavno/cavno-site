可以。李小龙特别适合用我们前面建立的“系统论观点”分析，因为他的思想并不是一套坐在书斋里完成的抽象哲学，而更像是：

Bruce Lee=Practical Philosopher+Martial Artist+System Experimenter+Self Designer \boxed{ Bruce\ Lee = Practical\ Philosopher + Martial\ Artist + System\ Experimenter + Self\ Designer }

他的核心问题始终是：

一个具体的人，怎样避免被既有形式、身份、传统和自我想象困住，在不断变化的现实中保持真实、有效而自由的行动？

这实际上与我们此前讨论的复杂适应系统高度契合。

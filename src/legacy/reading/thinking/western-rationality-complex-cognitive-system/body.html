MECHANICAL SYSTEM

机械系统范式

前系统思想至一般系统理论之前。世界被理解为可以分解、计算和预测的机器。

核心问题
世界有什么规律？

古希腊 → 欧几里得 → 笛卡尔 → 牛顿

世界 = 可分解机器

从神话到结构

世界不再由 Gods 控制，而由 Structure 解释。这是认知信息系统的第一次升级。

神话叙事 → 结构解释

巴门尼德

提出变化背后存在稳定结构，在流变中寻找 Invariant。

寻找系统不变量

柏拉图

建立现实层与抽象层的区分，像现代系统工程一样构造模型。

具体世界 → 抽象模型

亚里士多德

世界不再只是元素集合，而被理解为关系组织，出现系统论萌芽。

元素集合 → 关系组织

欧几里得

公理—规则—证明—结论，构成封闭系统的最高形式。

高稳定性，但难以处理开放变化

笛卡尔—牛顿

世界可以数学描述；只要掌握状态与规律，原则上即可预测。

状态 + 规律 = 预测
System + Law → Prediction
GENERAL SYSTEM THEORY · 1940—1960

整体性出现

贝塔朗菲的转折：世界不是元素集合，而是关系系统。

核心问题
整体如何组织？

莱布尼茨 · 康德 · 黑格尔

元素 → 关系

莱布尼茨：从零件到单元网络

零件+外部联系→机器
内部活动单元+关系→系统

被动零件被具有内部活动性的单元替代，思想开始接近开放系统。

康德：观察者进入系统

认识不再只是 World，而是 World + Cognitive Structure。观察者的认知结构成为系统条件。

世界 + 观察者／认知结构

黑格尔：内部具有动力

系统不是静态结构；矛盾并非外部噪声，而成为推动变化的内在动力。

矛盾 → 变化 → 动态系统
世界不是元素集合，而是关系系统

社会、价值与权力成为循环关系

香农：信息成为变量

Matter + Energy + Information

语言转向

NON-EQUILIBRIUM & SELF-ORGANIZATION · 1960—1980

非平衡、自组织系统

开放系统不只是维持自身，还能够在远离平衡的条件下生成新的秩序。

核心问题
系统为什么能自己产生秩序？

普里戈金 · 哈肯

秩序生成

普里戈金：耗散结构

传统熵增呈现 Order → Chaos；开放生命系统通过输入能量，使 Chaos → Order 成为可能。

开放 + 能量流 → 新秩序

达尔文：演化秩序

生命秩序不是被预先设计，而是在变异、选择与环境互动中演化。

设计论 → 演化生成

黑格尔：矛盾的生产力

矛盾不是系统错误，而是结构变化与新形式生成的动力。

异常 → 张力 → 生成

哈肯：协同学

大量个体的相互作用形成整体秩序，鸟群、社会、文化和语言都可由此理解。

局部互动 → 宏观协同
Chaos + Flow + Interaction → Order
CHAOS & NONLINEARITY

混沌与非线性系统

决定论并不等于可预测性；简单规则也可能产生极其复杂的结果。

核心问题
为什么系统不可预测？

Lorenz · Mandelbrot

复杂结果
Small Difference → Huge Outcome

洛伦兹：蝴蝶效应

微小的初始差异能够被非线性过程持续放大，因此确定系统不等于可预测系统。

确定性 ≠ 可预测性

后结构主义映射

福柯与德里达关注差异、断裂和结构变动；微小差异可改变整体意义网络。

局部差异 → 整体结构改变

Mandelbrot：分形

复杂结构在不同尺度上呈现自相似模式。

尺度变化中的结构重复

文化系统映射

语言、制度与文明在个体、组织和宏观社会等尺度上显现相似关系模式。

局部—整体的跨尺度同型
COMPLEX ADAPTIVE SYSTEMS

复杂适应系统

系统进入生命阶段：它不仅存在和运行，还能够学习、适应与创造。

核心问题
系统如何学习与适应？

Holland · Kauffman · Gell-Mann

学习与演化

Holland：CAS

复杂适应系统由大量主体组成；主体之间的互动生成宏观秩序。

多主体互动 → 涌现秩序

社会哲学映射

马克思的生产关系与哈耶克的市场秩序，都可以重新解释为复杂适应系统。

分散行动者 → 社会结构

Kauffman：生命自组织

自然选择之外，生命系统本身还具有组织倾向。

目的论 → 生成论

Gell-Mann：复杂演化

从粒子到生命，再到文明，以复杂性作为统一的研究对象。

物理 → 生命 → 文明
Agents + Interaction + Adaptation → Emergence
NETWORK & COMPUTATIONAL COMPLEXITY

网络与计算复杂性

最新阶段将对象转化为关系网络，并让系统通过计算模型模拟自身。

核心问题
系统如何创造新系统？

Barabási · Watts · Newman · AI

关系与反身

网络科学

世界不再是对象集合，而是节点与边构成的关系网络。

Node + Edge = Network

从实体到关系

哲学重心由实体是什么，转向关系如何形成并维持结构。

实体哲学 → 关系哲学

巴拉巴西：无尺度网络

许多真实系统不是均匀网络，而是少数中心节点连接大量外围节点。

互联网、城市、金融与知识传播

计算复杂性与 AI

系统开始模拟自身；AI标志着理性进入反身阶段。

05 / 最终统一模型

第一阶段

静态存在

从变化中寻找不变的存在和形式。

第二阶段

整体结构

理解部分如何通过关系组成整体。

第三阶段

运行机制

解释系统如何借助信息和反馈运行。

第四阶段

生成秩序

探索非平衡与局部互动怎样自发成序。

第五阶段

演化规律

智能网络自我创造

系统模拟自身，并生成新的认知系统。

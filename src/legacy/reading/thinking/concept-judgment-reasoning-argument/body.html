Formal logic × Systems thinking

概念—判断—推理—论证一个动态自校正的认知系统

形式逻辑不只是四个静态名词。它们构成一条从现实到公共知识的加工链：概念决定看见什么，判断决定承诺什么，推理决定如何更新，论证决定为何值得共同接受。

CORE THESIS · 核心命题

认知质量不只取决于推导是否有效，还取决于概念切分是否合适、判断是否与证据匹配、论证是否经得起他者与现实的双重检验，以及系统能否把错误反馈到正确的层级。

01 / MAP

四个问题，四次认知跃迁

每一层都接收上一层的输出，同时加入一种此前没有的新能力。它们不是简单并列，而是逐层扩大系统边界。

01 · CUT

概念

Concept

“我把现实中的什么，看成什么？”

输出：可复用的对象、类别、属性与关系。

02 · COMMIT

判断

Judgment

“在这个概念框架下，我承诺什么成立？”

输出：带语境、证据与置信度的命题承诺。

03 · TRANSFORM

推理

Reasoning

“怎样从已有判断生成、检验并更新新判断？”

输出：候选结论、解释、证明或决策。

04 · EXPOSE

论证

Argument

“为什么别人应接受它？怎样公开检查？”

输出：可质疑、可复核、可修订的理由结构。

概念、判断与推理可以发生在单一认知主体内部。

03 / CONCEPT

概念系统：先决定世界如何出现

逻辑在概念之后开始工作。若切分现实的方式有误，形式上完美的推导也可能只是在错误地图上精确前进。

CRepresentation layer

概念不是词义盒子，而是可更新的关系系统

它把连续、复杂、无限细节的现实，压缩为可识别、可比较、可组合、可预测的认知单位。

词只是概念的标签；定义只是概念的一个接口；集合只是概念的一种形式表示。概念还包含原型、边界、关系、用途与更新规则。

Concept = Representation + Boundary + Features + Examples + Relations + InferentialRole + Context + UpdateRules

系统变量

X对象域：概念试图覆盖什么
F特征：用于识别和比较的维度
B边界：成员与非成员如何区分
P原型 / 范例：典型成员与边界案例
R关系：与上位、下位、相邻概念的连接
I推理角色：它允许推出或排除什么
K语境：任务、文化、尺度与背景知识
U更新规则：反例出现时如何修订

基本变换

差异探测：从连续经验中发现稳定差异。
边界形成：决定哪些差异重要、哪些暂时忽略。
关系嵌入：把概念放入分类、因果和功能网络。
预测检验：看它能否支持识别、解释与行动。
概念修订：通过分裂、合并、重命名或换维度更新。

典型故障

!
边界错误把连续差异硬切成错误类别，或遗漏关键成员。
!
概念实体化把分析工具误当作世界中天然存在的实体。
!
维度遗漏只沿熟悉维度分类，看不见更有解释力的差异。
!
概念锁定面对反例只修补判断，却拒绝重画概念边界。

元层能力

✓
边界审计检查必要条件、充分条件、典型例与反例。
✓
多表征切换在集合、原型、网络、过程等表示之间切换。
✓
本体重构当旧分类持续失败时，重设对象与关系。
04 / JUDGMENT

判断系统：把表示转化为承诺

概念提供“能说什么”，判断决定“此刻愿意承诺什么”。判断不是孤立命题，而是主体在证据、语境与目标下形成的可更新认知状态。

JCommitment layer

判断 = 状态判定 + 关系绑定 + 置信承诺

它把若干概念组织成关于世界的内容，并标明这个内容是真、可能、必要，还是仅在特定条件下值得行动。

一句话是语言表达；命题是它表达的可真可假内容；判断则进一步加入主体、证据、语境、置信度和承诺后果。

Judgment = ConceptBinding + RelationAssignment + Truth/EvidenceAssessment + Context + Commitment

系统变量

C参与判断的概念
R主体、谓词、因果或比较关系
Q全称、存在、可能、必要等限定
E当前可用证据及其质量
K背景知识、时间与语境
M模态、真实性与置信强度
V核验、校准与反例机制
A可支持的行动与后续推理

句子、命题、判断

句子

“明天下雨。”
语言载体

命题

明天下雨这一可真可假的内容

判断

更新机制

Jt+1 = Update(Jt, Et+1, Kt+1)

典型故障

!
证据—强度失配有限证据却支持全称、必然或高度确信的结论。
!
语境塌缩把局部、短期、特定条件下成立误写成普遍成立。
!
描述与评价混淆事实判断、价值判断与行动判断未分层。
!
承诺惯性新证据出现后，因身份或沉没成本拒绝更新。

元层能力

✓
置信校准让主张强度与证据质量相称。
✓
承诺分层区分“相信”“暂定”“行动上采用”和“仅供探索”。
✓
撤回条件显式化预先说明什么新证据会使判断改变。
05 / REASONING

推理系统：在可能空间中受控搜索

逻辑规则只是推理的操作组件之一。完整推理还需要问题表示、目标、知识、启发式、记忆、验证器与资源分配。

RTransformation layer

推理不是直线，而是“生成—检验—修订”闭环

给定不完整的当前状态，认知主体通过允许的操作与搜索策略，逐步抵达一个能通过验证阈值的新状态。

演绎保证条件性的有效；归纳从样本扩展；溯因寻找最佳解释；类比迁移结构；模拟与反事实探索“如果改变会怎样”。

Reasoning = Representation + Knowledge + Operators + Search + Memory + Verification + Feedback + ResourceAllocation

关键区别：有效性回答“若前提真，结论是否跟随”；推理质量还要回答“前提从哪来、路径是否相关、是否遗漏替代解释、成本是否可接受”。

典型故障

!
表示错误问题一开始就被编码错；搜索越深，偏离越远。
!
搜索近视只考察熟悉路径，过早停止或陷入局部最优。
!
无效或不相关推导结论不由前提支持，或虽有效却没有回答问题。
!
验证器同源偏差生成与检查共享同一盲点，形成虚假自洽。

元层能力

✓
策略切换知道何时从演绎换为溯因、类比、模拟或外部检索。
✓
验证器设计用不同机制检查：反例、独立证明、实验或红队。
✓
资源管理在搜索深度、时间成本和结论价值之间动态平衡。
06 / ARGUMENT

论证系统：让推理进入公共空间

推理是认知状态的转换；论证是把这种转换外部化，使别人能检查前提、证据、推导、担保与反驳条件。

APublic inspection layer

论证 = 可公开检查的推理系统

它不只是“前提 → 结论”，而是一个包含支持、挑战、核验和修订的社会性反馈结构。

论证把 Other Mind 纳入系统。反对者不只是阻力，而是错误检测组件；实验、数据和重复则让现实本身成为外部验证器。

Argument = Claim + Premises + Evidence + Inference + Warrant + Defeaters + Verification + Revision
Evidence · 证据观察、数据、记录与可重复事实
WARRANT · 担保机制
Claim · 主张希望受众接受的判断，以及其强度限定。公开检验后，它被接受、降级、暂缓或修订。
Premises · 前提显式假设、背景条件与共享知识
Inference · 推导证据与前提如何抵达结论
Defeaters → 挑战支持链　·　Verification → 独立检查　·　Revision → 更新主张 / 前提 / 担保
有效性 Validity
P 为真 ⇒ C 必然跟随？

只检查内部推导结构，不保证前提真实。

可靠性 Soundness
有效推导 + 真实前提

比有效性更强，但仍未涵盖全部现实论证质量。

论证质量 Quality
Soundness + Evidence + Defeaters + Openness

还看证据质量、语境、反驳处理与修订能力。

八个必要组件

CClaim：核心主张与限定强度
PPremises：前提与背景假设
EEvidence：经验与数据支持
RInference：从支持到结论的路线
WWarrant：为何这些支持足以关联结论
DDefeaters：反例、例外与削弱条件
VVerification：复核、实验与对话标准
MRevision：谁在何种条件下如何修改

动态反馈

提出主张：说明希望改变哪个判断。
公开支持：列出前提、证据、推导和担保。
允许挑战：攻击前提、推导、证据或适用范围。
独立核验：由他者、制度或现实进行复核。
修订系统：修改结论强度，必要时回溯到概念层。

典型故障

!
隐藏担保事实相同却因因果模型或价值假设不同得出相反结论。
!
形式有效但前提虚假内部一致掩盖了与现实脱节。
!
免疫化把一切反证改写为理论正确的证据，系统失去可错性。
!
说服替代求真受众心理、身份或权威压倒证据结构。

元层能力

✓
证明责任分配明确谁需举证、证据门槛多高、何时可暂缓判断。
✓
敌对验证主动引入强反方、红队、同行评议与交叉询问。
✓
制度化修订保存版本、记录反对意见，让撤回与更新有路径。

09 / SYNTHESIS

Dynamic Self-Correcting Cognitive System

统一模型不是一条只向前的流水线，而是多层反馈、可回溯、能重构自身表示与规则的开放系统。

St = { RealityModel, Concepts, Judgments, ReasoningPolicy, Arguments, VerificationRules, Memory }
认知系统在 t 时刻的联合状态
St+1 = Update(St, NewEvidence, Criticism, Consequences, MetaEvaluation)
LOOP 01 · INTERNAL内部一致性回路

检查概念兼容、判断一致与推导有效，避免系统自相矛盾。

LOOP 02 · EMPIRICAL现实证据回路

让观察、实验、预测与行动后果约束内部模型。

LOOP 03 · SOCIAL社会批判回路

由独立主体揭示盲点、隐藏假设和单一验证器的偏差。

观察差异

先记录现象，不急于让旧概念吞没新信息。

声明概念

说明对象、边界、关系、尺度与使用目的。

形成判断

把证据、语境、限定词和置信度写进承诺。

展开推理

列出前提、操作、替代路径、资源与停止条件。

外化论证

公开 Claim、Evidence、Inference 与 Warrant。

真正高级的理性，不是让每个判断一开始就绝对正确；而是让错误更容易暴露、更难扩散、更低成本地被修正，并在必要时允许系统改变自己的概念与规则。
10 / NOTES

使用边界与三个提醒

这是一个系统论重构框架：它连接形式逻辑、认识论、认知科学与论证理论，但不把这些传统强行等同。

01 · 判断不等于命题

命题是可真可假的内容；这里的“判断”强调主体对命题的证据评估、置信度和认知承诺。

02 · 推理不等于逻辑

逻辑研究保真规则；真实推理还包括表示、搜索、记忆、验证、资源分配与错误恢复。

03 · 论证不等于证明

严格证明是论证的特殊形态。现实论证通常是可撤销的，需要处理证据质量、例外、受众和新信息。

04 · 说服不等于真

修辞效果可以促进接受，却不能替代前提可靠性、推导有效性、现实证据与独立复核。

# 四代矩阵

二十七个系统 × 四个版本 —— 每一格是一个动作，不是一段描述

读法只有一条：格子里写的不是"这个系统那时候是什么样"，是**它遇到自己消化不了的输入时做了什么**。 空格不填补——**缺席**（该代从未运转）、**未遂**（点了火又扑灭）、**拒**（拒绝这一刀）、**未竟**（建了元层但不独立） 都如实标记：一个系统缺哪一代，往往比它有哪一代更能说明它怎么死。

1.0封闭拒收

立 A=A，把消化不了的判为噪声、异端、误差。

脆断，零降级模式

2.0耗散燃烧

把矛盾接上传动轴当燃料，远离平衡态自组织。

无刹车；引擎审计不了引擎

3.0分层位移

把矛盾搬到另一层级：对象语言／元语言之塔。

盲点只上移不消除；塔无顶格

4.0生态共存

多方案并存，有效性环境相对；悬置成为引擎舱。

万能溶剂；层间绝缘失效

**空格的读法。**法家缺 2.0（变异即乱，故无降级模式，秦十五年脆断）；王朝的 2.0 是未遂（王安石把引擎装在 1.0 母体上，排异成党争）、4.0 缺席（循环拓扑不是梯上一格，是另一种形状）； 道家在 1.0 处是"拒"——它不占代际，站的是序位，拒绝的是那第一刀本身。 **三个不走梯的行。**佛教是双轨（教义 4.0 ∥ 制度 1.0，两千年互不转化，证伪了"一系统一代际"）； 金融微观是共时（四代同秒运转，代际从历史阶段退化为运行模式——这是账上最重的一笔）； 意识与个体—社会是镜厅（观察者入画，零余量）。第 27 行是把透镜转向透镜自己：四格全是假设语气，因为给它下判词需要一个它拿不到的元语言。

认知操作系统 · 四代矩阵　·　判据：遇到架构消化不了的输入时的处置动作  
 **代际是策略光谱，不是先进／落后排名**　·　阶梯是倒的：最宽的底座永远是最老那层  
 **四代可共时**：版本是场合的函数，断代前先查共时　·　协议 ≠ 实现　·　代际是关系不是属性  
 **形态可断言，时点须悬置**　·　添的是一层而非顶层——绘图者所在的楼层不在图上　·　未济

# 概念—判断—推理—论证一个动态自校正的认知系统

形式逻辑不只是四个静态名词。它们构成一条从现实到公共知识的加工链：**概念决定看见什么，判断决定承诺什么，推理决定如何更新，论证决定为何值得共同接受。**

CORE THESIS · 核心命题

认知质量不只取决于推导是否有效，还取决于概念切分是否合适、判断是否与证据匹配、论证是否经得起他者与现实的双重检验，以及系统能否把错误反馈到正确的层级。

**4**认知加工层

**8**动态闭环节点

**3**验证回路

**1**统一认知系统

**现实**尚未被完整编码的环境与事件

**概念化**切分、压缩、命名与关系化

**判断**形成有条件的认知承诺

**推理**生成、搜索、检验与更新

**论证**把理由结构公开化

**社会验证**质疑、复核、实验与对话

**修正判断**调整真值、强度与行动承诺

**修订概念**重画边界、关系与本体结构

修订后的概念框架重新进入下一轮观察；终点同时也是新起点。

01 / MAP

## 四个问题，四次认知跃迁

每一层都接收上一层的输出，同时加入一种此前没有的新能力。它们不是简单并列，而是逐层扩大系统边界。

01 · CUT

### 概念

Concept

“我把现实中的什么，看成什么？”

输出：可复用的对象、类别、属性与关系。

02 · COMMIT

### 判断

Judgment

“在这个概念框架下，我承诺什么成立？”

输出：带语境、证据与置信度的命题承诺。

03 · TRANSFORM

### 推理

Reasoning

“怎样从已有判断生成、检验并更新新判断？”

输出：候选结论、解释、证明或决策。

04 · EXPOSE

### 论证

Argument

“为什么别人应接受它？怎样公开检查？”

输出：可质疑、可复核、可修订的理由结构。

Private cognition**主体内部：形成与更新信念**

概念、判断与推理可以发生在单一认知主体内部。

Public inspection**主体之间：暴露与校正理由**

论证加入“他者”，把私有推理升级为社会纠错机制。

02 / MATRIX

## 四层横向对比

同一认知活动在不同层级上有不同输入、操作、质量标准和元问题。混淆层级，是许多争论无效的根源。

| 维度 | 概念 Concept | 判断 Judgment | 推理 Reasoning | 论证 Argument |
| --- | --- | --- | --- | --- |
| 核心功能 | 表示与组织现实 | 对世界状态作承诺 | 转换与更新认知状态 | 公开正当化一个判断 |
| 主要输入 | 经验、差异、目的、语言 | 概念、关系、证据、语境 | 判断、知识、目标、资源 | 主张、前提、证据、受众 |
| 关键操作 | 区分、抽象、压缩、关联 | 绑定、量化、模态化、赋信 | 生成、搜索、演绎、归纳、溯因 | 呈示、担保、回应、反驳、修订 |
| 典型输出 | 类别 / 属性 / 关系结构 | 可真可假、可强可弱的承诺 | 新结论 / 解释 / 计划 | 可公开检查的理由网络 |
| 首要标准 | 有用区分 + 解释力 | 证据匹配 + 置信校准 | 有效性 + 相关性 + 效率 | 前提可靠 + 推导透明 + 可回应 |
| 主要验证 | 反例、边界案例、预测效果 | 事实核验、概率校准、行动后果 | 证明、实验、模拟、反事实 | 批判、同行复核、交叉询问、重复 |

03 / CONCEPT

## 概念系统：先决定世界如何出现

逻辑在概念之后开始工作。若切分现实的方式有误，形式上完美的推导也可能只是在错误地图上精确前进。

CRepresentation layer

### 概念不是词义盒子，而是可更新的关系系统

它把连续、复杂、无限细节的现实，压缩为可识别、可比较、可组合、可预测的认知单位。

词只是概念的标签；定义只是概念的一个接口；集合只是概念的一种形式表示。概念还包含原型、边界、关系、用途与更新规则。

**Concept** = Representation + Boundary + Features + Examples + Relations + InferentialRole + Context + UpdateRules

#### 系统变量

**X**对象域：概念试图覆盖什么

**F**特征：用于识别和比较的维度

**B**边界：成员与非成员如何区分

**P**原型 / 范例：典型成员与边界案例

**R**关系：与上位、下位、相邻概念的连接

**I**推理角色：它允许推出或排除什么

**K**语境：任务、文化、尺度与背景知识

**U**更新规则：反例出现时如何修订

#### 基本变换

**差异探测：**从连续经验中发现稳定差异。

**边界形成：**决定哪些差异重要、哪些暂时忽略。

**关系嵌入：**把概念放入分类、因果和功能网络。

**预测检验：**看它能否支持识别、解释与行动。

**概念修订：**通过分裂、合并、重命名或换维度更新。

#### 典型故障

*!*

**边界错误**把连续差异硬切成错误类别，或遗漏关键成员。

*!*

**概念实体化**把分析工具误当作世界中天然存在的实体。

*!*

**维度遗漏**只沿熟悉维度分类，看不见更有解释力的差异。

*!*

**概念锁定**面对反例只修补判断，却拒绝重画概念边界。

#### 元层能力

*✓*

**边界审计**检查必要条件、充分条件、典型例与反例。

*✓*

**多表征切换**在集合、原型、网络、过程等表示之间切换。

*✓*

**本体重构**当旧分类持续失败时，重设对象与关系。

04 / JUDGMENT

## 判断系统：把表示转化为承诺

概念提供“能说什么”，判断决定“此刻愿意承诺什么”。判断不是孤立命题，而是主体在证据、语境与目标下形成的可更新认知状态。

JCommitment layer

### 判断 = 状态判定 + 关系绑定 + 置信承诺

它把若干概念组织成关于世界的内容，并标明这个内容是真、可能、必要，还是仅在特定条件下值得行动。

一句话是语言表达；命题是它表达的可真可假内容；判断则进一步加入主体、证据、语境、置信度和承诺后果。

**Judgment** = ConceptBinding + RelationAssignment + Truth/EvidenceAssessment + Context + Commitment

#### 系统变量

**C**参与判断的概念

**R**主体、谓词、因果或比较关系

**Q**全称、存在、可能、必要等限定

**E**当前可用证据及其质量

**K**背景知识、时间与语境

**M**模态、真实性与置信强度

**V**核验、校准与反例机制

**A**可支持的行动与后续推理

#### 句子、命题、判断

**句子**

“明天下雨。”  
语言载体

**命题**

明天下雨这一可真可假的内容

**判断**

我基于证据，以 70% 置信度接受该命题

#### 更新机制

**Jt+1** = Update(Jt, Et+1, Kt+1)

#### 典型故障

*!*

**证据—强度失配**有限证据却支持全称、必然或高度确信的结论。

*!*

**语境塌缩**把局部、短期、特定条件下成立误写成普遍成立。

*!*

**描述与评价混淆**事实判断、价值判断与行动判断未分层。

*!*

**承诺惯性**新证据出现后，因身份或沉没成本拒绝更新。

#### 元层能力

*✓*

**置信校准**让主张强度与证据质量相称。

*✓*

**承诺分层**区分“相信”“暂定”“行动上采用”和“仅供探索”。

*✓*

**撤回条件显式化**预先说明什么新证据会使判断改变。

05 / REASONING

## 推理系统：在可能空间中受控搜索

逻辑规则只是推理的操作组件之一。完整推理还需要问题表示、目标、知识、启发式、记忆、验证器与资源分配。

RTransformation layer

### 推理不是直线，而是“生成—检验—修订”闭环

给定不完整的当前状态，认知主体通过允许的操作与搜索策略，逐步抵达一个能通过验证阈值的新状态。

演绎保证条件性的有效；归纳从样本扩展；溯因寻找最佳解释；类比迁移结构；模拟与反事实探索“如果改变会怎样”。

**Reasoning** = Representation + Knowledge + Operators + Search + Memory + Verification + Feedback + ResourceAllocation

#### 系统变量

**Xt**当前认知状态 / 问题表示

**Kt**知识、模型与前提集合

**Gt**问题目标与停止条件

**Ot**允许使用的推理操作

**Ht**搜索策略与启发式

**Mt**工作记忆与外部记忆

**Vt**证明、实验、批判等验证器

**Ct**时间、注意力与算力预算

#### 基本循环

生成候选  
Generate

评估候选  
Evaluate

修订路径  
Revise

**Xt+1** = T(Xt, K, G, O, H, M, V ; C)  
直到 V(Xn) ≥ Threshold

**关键区别：**有效性回答“若前提真，结论是否跟随”；推理质量还要回答“前提从哪来、路径是否相关、是否遗漏替代解释、成本是否可接受”。

#### 典型故障

*!*

**表示错误**问题一开始就被编码错；搜索越深，偏离越远。

*!*

**搜索近视**只考察熟悉路径，过早停止或陷入局部最优。

*!*

**无效或不相关推导**结论不由前提支持，或虽有效却没有回答问题。

*!*

**验证器同源偏差**生成与检查共享同一盲点，形成虚假自洽。

#### 元层能力

*✓*

**策略切换**知道何时从演绎换为溯因、类比、模拟或外部检索。

*✓*

**验证器设计**用不同机制检查：反例、独立证明、实验或红队。

*✓*

**资源管理**在搜索深度、时间成本和结论价值之间动态平衡。

06 / ARGUMENT

## 论证系统：让推理进入公共空间

推理是认知状态的转换；论证是把这种转换外部化，使别人能检查前提、证据、推导、担保与反驳条件。

APublic inspection layer

### 论证 = 可公开检查的推理系统

它不只是“前提 → 结论”，而是一个包含支持、挑战、核验和修订的社会性反馈结构。

论证把 Other Mind 纳入系统。反对者不只是阻力，而是错误检测组件；实验、数据和重复则让现实本身成为外部验证器。

**Argument** = Claim + Premises + Evidence + Inference + Warrant + Defeaters + Verification + Revision

**Evidence · 证据**观察、数据、记录与可重复事实

WARRANT · 担保机制

**Claim · 主张**希望受众接受的判断，以及其强度限定。公开检验后，它被接受、降级、暂缓或修订。

**Premises · 前提**显式假设、背景条件与共享知识

**Inference · 推导**证据与前提如何抵达结论

**Defeaters** → 挑战支持链　·　**Verification** → 独立检查　·　**Revision** → 更新主张 / 前提 / 担保

**有效性 Validity**

P 为真 ⇒ C 必然跟随？

只检查内部推导结构，不保证前提真实。

**可靠性 Soundness**

有效推导 + 真实前提

比有效性更强，但仍未涵盖全部现实论证质量。

**论证质量 Quality**

Soundness + Evidence + Defeaters + Openness

还看证据质量、语境、反驳处理与修订能力。

#### 八个必要组件

**C**Claim：核心主张与限定强度

**P**Premises：前提与背景假设

**E**Evidence：经验与数据支持

**R**Inference：从支持到结论的路线

**W**Warrant：为何这些支持足以关联结论

**D**Defeaters：反例、例外与削弱条件

**V**Verification：复核、实验与对话标准

**M**Revision：谁在何种条件下如何修改

#### 动态反馈

**提出主张：**说明希望改变哪个判断。

**公开支持：**列出前提、证据、推导和担保。

**允许挑战：**攻击前提、推导、证据或适用范围。

**独立核验：**由他者、制度或现实进行复核。

**修订系统：**修改结论强度，必要时回溯到概念层。

#### 典型故障

*!*

**隐藏担保**事实相同却因因果模型或价值假设不同得出相反结论。

*!*

**形式有效但前提虚假**内部一致掩盖了与现实脱节。

*!*

**免疫化**把一切反证改写为理论正确的证据，系统失去可错性。

*!*

**说服替代求真**受众心理、身份或权威压倒证据结构。

#### 元层能力

*✓*

**证明责任分配**明确谁需举证、证据门槛多高、何时可暂缓判断。

*✓*

**敌对验证**主动引入强反方、红队、同行评议与交叉询问。

*✓*

**制度化修订**保存版本、记录反对意见，让撤回与更新有路径。

07 / FAILURE

## 错误如何沿系统传播

认知错误很少只停留在发生处。越底层的错误，传播半径越大；越晚发现，纠错成本越高。

C

### 概念偏差

边界、维度或关系被错误设定

J

### 判断失真

在错误地图上形成过强承诺

R

### 推理放大

有效规则精确放大初始偏差

A

### 论证包装

结构清晰使错误更具可信度

S

### 社会扩散

权威、网络与制度复制结论

↺

### 反馈固化

行动改变环境，反过来确认模型

CONTAIN / 01**在概念层截断**寻找反例、边界案例与替代分类，成本最低。

CONTAIN / 02**在判断层降级**降低置信度、缩小适用范围、显式加入条件。

CONTAIN / 03**在推理层复核**重做表示、枚举替代路径、使用独立验证器。

CONTAIN / 04**在公共层纠错**公开证据、欢迎挑战、记录撤回并更新制度。

**Correction Priority** ∝ ErrorPropagationRadius × CorrectionLatency × DecisionImpact

08 / META

## 元认知：不仅修答案，还修产生答案的系统

低阶纠错更换结论；高阶纠错会追问表示、搜索、验证和对话规则本身是否需要改变。

L5**制度 / 元规则**谁能质疑？谁承担证明责任？怎样保存和修订知识？*治理论证系统*

L4**论证结构**支持链是否透明？反驳、核验与修订接口是否开放？*检查可公开性*

L3**推理策略**操作、搜索、资源与验证器是否适合当前问题？*调整认知过程*

L2**判断承诺**结论强度、语境与证据是否匹配？*校准置信*

L1**概念框架**对象、边界、属性和关系是否切分得当？*重画地图*

L0**现实耦合**系统是否仍能接收真实、及时、未被过滤的反馈？*保持可错性*

**一阶学习**

在既定概念、规则和目标下，改进具体答案。

→

**二阶学习**

改变产生答案的概念、策略、验证器或制度规则。

09 / SYNTHESIS

## Dynamic Self-Correcting Cognitive System

统一模型不是一条只向前的流水线，而是多层反馈、可回溯、能重构自身表示与规则的开放系统。

**St** = { RealityModel, Concepts, Judgments, ReasoningPolicy, Arguments, VerificationRules, Memory }

认知系统在 t 时刻的联合状态

**St+1** = Update(St, NewEvidence, Criticism, Consequences, MetaEvaluation)

LOOP 01 · INTERNAL**内部一致性回路**

检查概念兼容、判断一致与推导有效，避免系统自相矛盾。

LOOP 02 · EMPIRICAL**现实证据回路**

让观察、实验、预测与行动后果约束内部模型。

LOOP 03 · SOCIAL**社会批判回路**

由独立主体揭示盲点、隐藏假设和单一验证器的偏差。

**观察差异**

先记录现象，不急于让旧概念吞没新信息。

**声明概念**

说明对象、边界、关系、尺度与使用目的。

**形成判断**

把证据、语境、限定词和置信度写进承诺。

**展开推理**

列出前提、操作、替代路径、资源与停止条件。

**外化论证**

公开 Claim、Evidence、Inference 与 Warrant。

**主动求败**

寻找最强反例、反方解释与独立验证器。

**分层修订**

判断故障来自结论、推导，还是更底层概念。

**保留记忆**

记录版本、错误类型与纠错路径，改进下一轮。

真正高级的理性，不是让每个判断一开始就绝对正确；而是让错误更容易暴露、更难扩散、更低成本地被修正，并在必要时允许系统改变自己的概念与规则。

## 使用边界与三个提醒

这是一个系统论重构框架：它连接形式逻辑、认识论、认知科学与论证理论，但不把这些传统强行等同。

### 01 · 判断不等于命题

命题是可真可假的内容；这里的“判断”强调主体对命题的证据评估、置信度和认知承诺。

### 02 · 推理不等于逻辑

逻辑研究保真规则；真实推理还包括表示、搜索、记忆、验证、资源分配与错误恢复。

### 03 · 论证不等于证明

严格证明是论证的特殊形态。现实论证通常是可撤销的，需要处理证据质量、例外、受众和新信息。

### 04 · 说服不等于真

修辞效果可以促进接受，却不能替代前提可靠性、推导有效性、现实证据与独立复核。

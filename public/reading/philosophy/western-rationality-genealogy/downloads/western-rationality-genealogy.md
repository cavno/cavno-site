# 西方理性  
全谱系

从“变化背后的不变形式”，到“让规则运行出世界”，再到模型、规则、目标与观察者共同更新的多层反身适应理性。

这不是一条从落后到先进的单线进步史，而是一棵不断分叉、竞争、遭遇边界、提高闭合层级、再度汇流的树。“闭合证明 → 开放生成”是深层主轴，却不是全部。

什么算作  
“理解”

**证明**从第一原理推出必然结论

**生成**由状态与规则运行出历史

**学习**让元规则从数据形成规则

**反身**连模型、目标与观察者也更新

完成的结构开放的过程

01 / 母题

### 在变化中寻找不变

“如果现实不停变化，稳定知识何以可能？”柏拉图的形式、物理定律、守恒量、结构与算法，都是对这道母题的不同回答。

02 / 转向

### 从答案转向生成器

欧几里得—斯宾诺莎把世界理解为可证明的完成结构；莱布尼茨—拉格朗日把理解改写为掌握运算与演化规则。

03 / 边界

### 确定不等于可预测

概率、混沌、不完全性、不可判定与有限理性表明：拥有规律并不等于能预先压缩所有结果。

04 / 当前

### 可修正性成为高阶不变量

当状态、规则、模型、目标和环境都可能改变，理性不再是一次封闭，而是持续建模、行动、反馈、协调和反思的能力。

01 · OVERVIEW

## 先看主干：什么叫“真正理解”

每个时代都在重写理解的判准：从知道“是什么、为什么必然如此”，到能预测、运行、纠错、干预、学习，并反思自己的模型与目标。

Being → Form → Proof → Evidence → Law → Dynamics → Probability → Structure → Computation → Feedback → Adaptation → Learning → Reflexivity

**存在**什么真正存在

**形式**变化背后的不变

**证明**从第一原理必然推出

**证据**观察与实验支持

**定律**统一可重复现象

**动力**规则生成时间轨迹

**概率**不确定性中的更新

**结构**关系与变换的不变量

**计算**可机械执行的过程

**反馈**按行动结果纠偏

**适应**在环境中维持与演化

**学习**从数据形成规则

**反身**审视模型、目标与自身

**不是替代关系**  
证明、实验、概率、解释与学习今天仍并存；后来者通常重新定位早先理性，而非简单取消它。

**不是单一路径**  
自然科学、数学、历史哲学、语言解释、社会行动与技术系统，对“闭合失败”给出了不同回答。

**不是绝对开放**  
每次开放都把不变量上移：结论开放时规则仍固定；规则开放时学习机制仍相对固定；再往上则审查学习机制与目标。

03 · HISTORICAL LAYERS

## 十二个历史层：理性的对象不断改变

这里的阶段是结构分层，而非精确断代。相邻层长期重叠；每一次转折，都是某种旧判准遇到它无法内部解决的问题。

前 6–4 世纪

LAYER 01

### 原始张力：存在与生成

如果现实不断变化，稳定知识如何可能？

巴门尼德赫拉克利特柏拉图亚里士多德

**结构转变**从神话叙事转向可论证的本原、形式与因果。

Change → search for Invariant

前 3 世纪

LAYER 02

### 公理—证明机器

怎样从有限第一原理得到必然知识？

欧几里得亚里士多德

**结构转变**欧几里得把定义、公设、共同观念与证明组织成无时间的逻辑闭包。

Axioms + inference → theorems

4–15 世纪

LAYER 03

### 神学—本体论闭包

理性怎样进入一个由创造与目的统摄的秩序？

奥古斯丁阿奎那奥卡姆

**结构转变**经院哲学保存并细化逻辑、因果与论证，同时争论信仰、理性、共相和语言。

God → order → reason discovers order

16–17 世纪

LAYER 04

### 近代大分叉：演绎与证据

确定性来自清楚的第一原理，还是可重复的经验？

培根笛卡尔斯宾诺莎莱布尼茨洛克

**结构转变**笛卡尔—斯宾诺莎—莱布尼茨追求普遍方法；培根—洛克—休谟把观察、实验与归纳问题置于中心。

Deduction ↔ Evidence

17–18 世纪

LAYER 05

### 生成转向：微积分与动力学

与其枚举世界的全部状态，能否给出产生其历史的规则？

莱布尼茨牛顿欧拉拉格朗日拉普拉斯

**结构转变**对象从 x 变成 x(t)；世界从“已写完的定理”变成“必须运行的动力系统”。

Law + initial state → trajectory

18–19 世纪

LAYER 06

### 主体与历史进入机器

认知结构是否参与经验构成？规则本身能否被历史改变？

休谟康德黑格尔马克思

**结构转变**康德把主体条件纳入经验；黑格尔把矛盾与规则变化内生化，形成不同于固定法则动力学的历史生成。

xₜ₊₁ = Fₜ(xₜ); Fₜ₊₁ = G(Fₜ,xₜ)

19 世纪

LAYER 07

### 确定性裂变：多几何、进化与概率

如果公理可选择、秩序无蓝图、宏观规律来自分布，什么仍算知识？

黎曼达尔文麦克斯韦玻尔兹曼

**结构转变**非欧几何把公理变成结构选择；达尔文展示选择生成秩序；玻尔兹曼以概率分布连接微观与宏观。

Possibilities + selection/statistics → order

1890–1945

LAYER 08

### 结构、形式化与内在极限

数学能否完全公理化？过程能否被机械定义？

弗雷格罗素希尔伯特布劳威尔哥德尔图灵

**结构转变**集合、逻辑与希尔伯特纲领重启闭合工程；哥德尔给出不完全性，图灵刻画可计算过程及不可判定边界。

Formalization ≠ complete closure

1870–1970

LAYER 09

### 实用、过程、语言与科学变迁

意义能否脱离行动、过程、生活世界、语言与历史框架？

皮尔士杜威柏格森怀特海胡塞尔维特根斯坦库恩

**结构转变**实用主义把错误与开放探究内生化；过程哲学把生成提升为本体论；现象学—解释学、语言哲学与科学史又把语境和框架变化变成对象。

Meaning = use + context + history + consequences

1940–1980

LAYER 10

### 信息、反馈、博弈与有限理性

系统怎样在噪声和多主体环境中行动并维持自身？

香农维纳冯·诺依曼纳什西蒙

**结构转变**香农度量信息；维纳以内反馈控制；冯·诺依曼汇合计算、策略与自复制；西蒙把资源限制纳入理性。

Sense → model → act → feedback

1970–2010

LAYER 11

### 复杂适应、因果干预与学习

局部规则如何涌现宏观秩序？如何从相关进入干预？

普里高津霍兰德马图拉纳瓦雷拉Pearl连接主义者

**结构转变**复杂系统研究可能运行空间；因果模型表达反事实；联结主义让具体规则从数据与误差中形成。

Meta-rule + data → learned rule

2010–当前

LAYER 12

### 多层反身适应理性

当模型、规则、目标、环境和观察者都变化，怎样保持可纠错与可治理？

现代 AI复杂系统因果科学人机协作制度治理

**结构转变**符号、概率、因果、神经学习、工具使用和多主体协调重新汇流；高阶不变量变成可修正、可审计与可协商。

State + rule + model + goal + observer co-evolve

04 · RECURSIVE CLOSURE

## 真正的主线：闭合层级四次迁移

不是从 closed 简单走向 open，而是从“结果闭合”转向“规则闭合、结果开放”，再转向“元规则相对稳定、具体规则开放”，最终进入可反思的暂时闭合。

第一层 · 证明闭合

### 世界作为定理

Axioms + Rules  
→ Theorem Closure

- 起点：定义、公理、第一原理
- 操作：无时间性的演绎
- 理想：有限起点封闭无限真理
- 典型：欧几里得、斯宾诺莎

第二层 · 生成闭合

### 世界作为运行

State0 + Fixed Rule  
→ Open History

- 起点：初始状态与局部法则
- 操作：微分、迭代、模拟
- 理想：压缩历史而非枚举历史
- 典型：莱布尼茨、拉格朗日

第三层 · 学习闭合

### 规则成为输出

Meta-rule + Data  
→ Rule → Output

- 起点：数据、损失、更新机制
- 操作：统计推断与优化学习
- 开放：模型参数乃至程序结构
- 典型：贝叶斯、联结主义、机器学习

第四层 · 反身闭合

### 连目标也可修订

Observer ↔ Model ↔ Action  
↕ Goal ↔ Environment

- 对象：状态、规则、模型、目标、观察者
- 操作：反馈、协调、审计、制度修订
- 闭合：局部、暂时、可撤回
- 典型：二阶控制论、复杂适应系统、当代 AI 治理

### 元规律：不变量没有消失，而是不断上移

西方理性的深层连续性，不在于始终坚持某个固定对象，而在于不断寻找“变化中的可保持者”。当旧不变量被历史化、概率化或计算化，新的不变量就被放到更高层。

**对象**形式与本质

**命题**证明关系

**定律**状态变化规则

**分布**统计稳定性

**结构**关系与变换

**程序**可执行操作

**学习机制**从误差更新

**可修正性**反思与协调能力

05 · SEVENTEEN BRANCHES

## 十七条主线与支线：各自处理一种“闭合失败”

用筛选器聚焦一个问题家族；默认呈现全部。每条路线都保留它的核心问题、谱系、理性操作与内在张力。

ROUTE 01形式

### 演绎—公理化

什么能够被必然证明？

柏拉图 → 亚里士多德 → 欧几里得 → 笛卡尔／斯宾诺莎 → 希尔伯特

**操作**定义、演绎、证明

**贡献**建立可检查的必然性与形式保证。

**张力**第一原理来源、完备性与适用范围。

ROUTE 02证据

### 经验—实验

什么被观察、实验和可重复证据支持？

培根 → 洛克 → 休谟 → 逻辑经验主义 → 波普尔／科学实践

**操作**观测、实验、反驳、复现

**贡献**把错误与公共检验纳入知识。

**张力**归纳问题、测量负载与理论依赖。

ROUTE 03生成

### 动力—生成

世界怎样依照局部规则随时间产生自身？

莱布尼茨／牛顿 → 欧拉 → 拉格朗日／哈密顿 → 庞加莱 → 动力系统／模拟

**操作**微分、迭代、运行

**贡献**用生成器压缩无限历史。

**张力**初值敏感、不可积与计算不可约。

ROUTE 04概率

### 概率—统计

不确定性下怎样形成和更新合理信念？

帕斯卡 → 贝叶斯 → 拉普拉斯 → 玻尔兹曼 → 科尔莫哥洛夫 → 贝叶斯认识论

**操作**分布、条件化、更新

**贡献**把无知、噪声和群体规律形式化。

**张力**先验选择、模型错设与尾部风险。

ROUTE 05进化

### 进化—适应

没有中央蓝图的秩序怎样形成？

达尔文 → 群体遗传学 → 进化认识论 → 复杂适应系统 → 进化博弈

**操作**变异、选择、保留

**贡献**以历史筛选解释功能与秩序。

**张力**路径依赖、适应度环境与目的论误读。

ROUTE 06历史

### 辩证—历史生成

规则、制度与概念本身怎样被内部矛盾改变？

康德 → 黑格尔 → 马克思 → 法兰克福学派 → 批判理论

**操作**否定、冲突、扬弃、制度变迁

**贡献**把规则变化与社会历史内生化。

**张力**难以形式化、目的论与经验校验。

ROUTE 07结构

### 结构—关系—范畴

对象背后的不变量是否是关系与变换？

非欧几何 → 克莱因纲领 → Bourbaki → 结构主义 → 范畴论

**操作**同构、变换、函子、自然性

**贡献**在开放对象空间之上建立结构闭合。

**张力**高度抽象可能遮蔽生成、语境与材料性。

ROUTE 08意义

### 语言—现象学—解释

理性是否受语言、历史、身体与解释框架约束？

胡塞尔 → 海德格尔 → 伽达默尔；弗雷格 → 维特根斯坦 → 奥斯汀 → 奎因；尼采 → 福柯／德里达

**操作**描述、解释、语用、谱系批判

**贡献**揭示意义条件、生活世界与权力。

**张力**跨语境判准与形式可比较性。

ROUTE 09计算

### 形式系统—计算

什么可以机械证明、判定、执行与持续交互？

莱布尼茨 → 布尔／弗雷格 → 希尔伯特 → 哥德尔 → 图灵 → 程序语义／类型论／并发计算

**操作**符号化、算法、执行、交互、验证

**贡献**精确定义有效过程，并把计算对象从函数扩展到行为。

**张力**不完全、不可判定、资源爆炸与语义落差。

ROUTE 10反馈

### 信息—控制—自创生

系统怎样在噪声环境中维持自身并纠正行动？

香农 → 维纳 → 一般系统论 → 二阶控制论 → 自创生／具身认知

**操作**编码、反馈、调节、闭环

**贡献**把环境、行动结果与观察者纳入系统。

**张力**信息不等于意义；控制目标从何而来。

ROUTE 11互动

### 决策—博弈—有限理性

多个资源有限、相互预期的主体怎样行动？

效用理论 → 冯·诺依曼／摩根斯坦 → 纳什 → 西蒙 → 行为决策／机制设计

**操作**选择、策略、均衡、启发式

**贡献**从单主体真理进入多主体互动。

**张力**偏好构造、均衡多重性与制度权力。

ROUTE 12涌现

### 复杂性—涌现

局部简单规则为何产生不可压缩的宏观结构？

庞加莱 → 非平衡热力学 → 元胞自动机 → 混沌 → 复杂网络／多主体模型

**操作**模拟、相空间、涌现分析

**贡献**理解轨迹空间而不要求闭式答案。

**张力**模型依赖、尺度转换与解释过拟合。

ROUTE 13干预

### 因果—反事实—干预

如何从“X 与 Y 相关”进入“改变 X 会怎样”？

休谟的因果问题 → 实验设计 → 结构方程 → 潜在结果 → 因果图

**操作**随机化、do-干预、反事实

**贡献**把行动后果与机制显式化。

**张力**不可观测反事实、识别假设与外部效度。

ROUTE 14学习

### 联结主义—机器学习

若具体规则未知，能否让系统从数据中形成规则？

神经元模型／感知机 → 联结主义 → 统计学习 → 深度学习 → 生成模型

**操作**表示学习、优化、泛化

**贡献**从 Rule→Output 提升为 Meta-rule→Rule→Output。

**张力**分布漂移、黑箱、偏差、目标错设与鲁棒性。

ROUTE 15反身

### 反身—适应—治理

当观察者、模型、规则和目标都变时，什么仍叫理性？

康德 → 二阶控制论 → 自创生 → 复杂适应系统 → AI 审计／协同治理

**操作**监测、纠错、反思、协商、制度更新

**贡献**把自身条件和价值后果纳入循环。

**张力**无限元回归、责任分配与价值冲突。

ROUTE 16试错

### 实用主义—开放探究

如果知识会错，怎样让错误成为理性的生产条件？

皮尔士 → 詹姆斯 → 杜威 → 波普尔 → 库恩／拉卡托斯

**操作**探究、试验、纠错、共同体检验

**贡献**真理不再只是完成体系，而是在后果与批评中可持续改进的信念。

**张力**长期收敛是否成立、范式断裂、共识与权力。

ROUTE 17过程

### 过程哲学—生成本体论

如果生成不是描述世界的方法，而就是存在本身呢？

赫拉克利特 → 柏格森 → 怀特海 → 德勒兹／当代过程思想

**操作**事件、关系、持续、生成

**贡献**实体被重写为过程中暂时稳定的模式，存在本身不再先于变化。

**张力**形式精度、经验桥接与跨尺度说明。

06 · COMPARISON MATRIX

## 比较矩阵：十种理性机器如何工作

区别不只在结论，而在基本对象、有效操作、所保留的不变量，以及它最容易失败的地方。

| 范式 | 基本对象 | 核心操作 | 不变量／闭合位置 | 何谓理解 | 典型边界 |
| --- | --- | --- | --- | --- | --- |
| 几何／公理 | 定义明确的对象与命题 | 演绎、证明 | 公理与推理规则 | 把结果置入必然原因链 | 公理来源、不完备 |
| 经验／实验 | 可观察现象与测量 | 观察、归纳、反驳 | 可重复证据与方法规范 | 让主张经受公共检验 | 归纳与理论负载 |
| 动力／生成 | 状态、变量、时间轨迹 | 微分、迭代、模拟 | 演化法则 | 用规则产生历史 | 混沌与计算不可约 |
| 概率／统计 | 随机变量与分布 | 估计、条件化、更新 | 概率公理或稳定分布 | 校准不确定性并更新 | 模型错设与先验 |
| 进化／历史 | 种群、制度、概念与路径 | 变异、选择、冲突、保留 | 选择机制或历史约束 | 解释秩序如何无蓝图形成 | 路径依赖、目的论 |
| 结构／范畴 | 关系、变换与结构 | 同构、函子、自然变换 | 变换下的不变量 | 掌握结构保持的映射 | 脱离语境与材料 |
| 解释／语言 | 意义、经验、话语与实践 | 描述、诠释、语用分析 | 生活世界或语言规则 | 把对象置于语境与视域 | 判准相对与不可通约 |
| 计算／信息 | 符号、程序、消息与复杂度 | 编码、执行、压缩 | 算法或通信协议 | 给出可执行生成过程 | 停机、复杂度、意义 |
| 控制／决策 | 行动者、环境、目标与反馈 | 预测、选择、调节、博弈 | 目标函数或稳定回路 | 在后果中维持和纠偏 | 目标错设、多主体冲突 |
| 学习／反身 | 模型、策略、目标与观察者 | 训练、适应、审计、协商 | 可修订的更新机制 | 持续改进并审查自身条件 | 漂移、价值冲突、元回归 |

07 · INTERNAL LIMITS

## 九次边界发现：理性靠暴露自己的失败而升级

边界并不等于放弃理性。恰恰相反，它们把错误、有限资源、观察条件、历史框架与不可判定性纳入理性内部。

BOUNDARY 01

### 休谟：归纳缺口

**过去重复**⇣ 不保证 ⇣**不能逻辑保证未来重复**

开启：概率更新、可证伪与实践校准

BOUNDARY 02

### 非欧几何：公理多元

**唯一自明空间**⇣ 不保证 ⇣**不同公理生成不同一致几何**

开启：结构选择与模型复数

BOUNDARY 03

### 玻尔兹曼：统计层级

**逐粒子轨迹**⇣ 不保证 ⇣**宏观规律来自微观可能分布**

开启：概率、尺度与涌现

BOUNDARY 04

### 庞加莱：混沌

**决定论**⇣ 不保证 ⇣**不等于长期可预测**

开启：相空间、定性动力学与模拟

BOUNDARY 05

### 哥德尔：不完全

**一致有效形式化**⇣ 不保证 ⇣**不等于相关真理完全封闭**

开启：元数学与体系边界意识

BOUNDARY 06

### 图灵：不可判定

**可机械执行**⇣ 不保证 ⇣**不等于可由通用程序预判**

开启：计算作为运行而非先知

BOUNDARY 07

### 量子与测量

**观察者外在**⇣ 不保证 ⇣**测量安排进入可陈述现象**

开启：概率结构与操作条件

BOUNDARY 08

### 西蒙：有限理性

**全知全算最优者**⇣ 不保证 ⇣**现实主体受信息与算力约束**

开启：满意化、启发式与制度支持

BOUNDARY 09

### 库恩／二阶控制论

**固定框架中的纠错**⇣ 不保证 ⇣**框架与观察者也参与结果**

开启：范式变迁、反身观察与治理

08 · THE DEEP TRUNK

## 深层主干：从世界是定理，到规则从经验中形成

这条线解释了为何斯宾诺莎—莱布尼茨—拉格朗日—庞加莱—哥德尔—图灵会通向信息、反馈、复杂性和机器学习。

**斯宾诺莎**World = Proof

**莱布尼茨**Reason = Calculation

**拉格朗日**World = Generator

**庞加莱**Determinism ≠ Prediction

**哥德尔**Formalization ≠ Closure

**图灵**Rule + Execution

**香农**Information

**维纳**Feedback

**冯·诺依曼**Strategy + Self-reproduction

**现代 AI**Meta-rule → Rule

**斯宾诺莎**World = Proof

世界是一套必然关系；最高理性是从第一原理理解为何不可能不是如此。

**莱布尼茨**Reason = Calculation

推理可符号化，局部差异可经运算综合为整体；他是闭合体系与开放计算之间的铰链。

**拉格朗日**World = Evolution Law

不必写出世界全部历史，只需给出生成历史的方程和初始条件。

**庞加莱**Determinism ≠ Predictability

规则完全确定，也不保证长期结果可由有限认知者简洁预测。

**哥德尔**Formalization ≠ Complete Closure

足够强的一致有效形式体系，不能在自身证明活动中完全封闭相关算术真理。

**图灵**Computation = Rule + Execution

理性过程可以机械执行，但不存在通用程序预先解决所有程序的行为。

**香农／维纳**Information + Feedback

系统不只运行，还要在噪声中传递差异，并依据行动后果调节自身。

**现代学习系统**Meta-rule → Rule → Output

人不再逐条写出规则，而是规定学习机制，使模型从数据、误差与环境中形成。

09 · REFLEXIVE ADAPTATION

## 当前汇流：多层反身适应理性

当前最强的理性图景不是“知道所有答案”的主体，而是一个能建模、预测、干预、接收反馈、更新规则、与他者协调，并审查自身目标的分布式系统。

**世界／环境层**自然过程、制度、技术基础设施与他者都在变化；环境也会被行动反向改写。

**证据／测量层**观测不是透明窗口；测量、采样、语言与工具决定可见内容。

**模型／因果层**压缩经验、预测反事实，并区分相关、干预与机制。

反身审计  
模型 · 目标 · 权力

**观察**选择与测量

**建模**表征与解释

**预测**可能与反事实

**行动**干预与协调

**反馈**误差与后果

➜➜➜➜➜

**学习／适应层**模型、策略和规则依据误差更新；学习本身也受资源与偏差约束。

**互动／制度层**多主体相互预期；规范、市场、组织与协议协调局部理性。

**价值／治理层**“优化什么”不能由预测自动推出；目标必须接受公共反思、问责与修订。

st+1 = Ft(st, at, ξt)状态在行动与不确定性中变化

mt+1 = Learn(mt, ot+1, errort)模型根据新观察和误差更新

πt+1 = Adapt(πt, mt+1, feedback)策略依照模型与结果调整

gt+1 = Reflect(gt, outcomes, values, others)目标接受后果、价值与他者的反思

Ft+1 = CoEvolve(Ft, collective action)行动会改变下一轮所处的环境与规则

Rationality = model + act + correct + coordinate + reflect理性从“结论属性”转成“循环能力”

### 当代汇流不是“AI 取代理性”，而是多种理性组成复合架构

**符号证明**约束、验证、可解释推理与形式保证。

**统计学习**从不完整数据形成可更新模型。

**因果干预**从预测相关进入行动后的反事实。

**外部知识／工具**通过检索、记忆、程序和仪器扩展有限主体。

**反馈治理**监测后果，协调主体，修订规则与目标。

10 · SYNTHESIS

## 最终综合：开放生成只是中间站

最完整的叙述不是“闭合失败，所以开放获胜”，而是理性反复把自己的条件、边界与更新机制变成新的研究对象。

### 八条贯穿原则

1. 知识始于在变化中寻找不变。
2. 证明把真理组织成无时间的必然关系。
3. 实验把证据与可纠错性纳入知识。
4. 动力学用有限规则压缩无限历史。
5. 概率、进化与复杂性承认秩序可由不确定过程生成。
6. 哥德尔、图灵与混沌区分了确定、可证、可算与可预测。
7. 控制、博弈与因果把理性从观察推进到行动与互动。
8. 学习与反身性让模型、规则、目标和观察者逐层成为变量。

### 因此，“理性”被连续改写

**17 世纪：**我能证明世界为什么必然如此。

**18–19 世纪：**我能写出世界如何变化的方程。

**19 世纪末：**即使求不出精确轨迹，我能理解动力结构与概率分布。

**20 世纪：**我能形式化推理，也能刻画形式化、计算和预测的边界。

**当前：**我能在不完备环境中建模、行动、学习、协同，并修订自身模型与目标。

Truth as completed structure → Truth as generated process → Rule as learned model → Rationality as reflexive co-adaptation

最深的变化不是从“真”走向“无真”，而是从一次性拥有完成答案，转向掌握可执行规则、运行规则、研究可能运行空间、理解规则的极限，并保持在反馈中修订自身的能力。

11 · READING LANDMARKS

## 关键文本与校准说明

以下是谱系中的代表性路标，不是穷尽书目。页面中的现代公式是结构化重述，帮助比较不同范式，并非声称历史人物以这些符号原样表达。

1. 柏拉图：《理想国》《蒂迈欧篇》；亚里士多德：《后分析篇》《物理学》。
2. 欧几里得：《几何原本》；中世纪经院逻辑与托马斯·阿奎那的综合传统。
3. 培根：《新工具》；笛卡尔：《方法谈》《几何学》；斯宾诺莎：《伦理学》。
4. 莱布尼茨：普遍字符、推理演算与微积分相关论文；牛顿：《自然哲学的数学原理》。
5. 休谟：《人类理解研究》；康德：《纯粹理性批判》；黑格尔：《精神现象学》《逻辑学》。
6. 达尔文：《物种起源》；玻尔兹曼的统计力学；庞加莱：《科学与假设》《新天体力学方法》。
7. 布尔、弗雷格、罗素、希尔伯特的逻辑与基础研究；布劳威尔的直觉主义。
8. 哥德尔（1931）不完全性论文；图灵（1936）可计算数与判定问题论文。
9. 皮尔士、詹姆斯、杜威的实用主义；柏格森、怀特海的过程哲学。
10. 胡塞尔、海德格尔、伽达默尔的现象学—解释学；维特根斯坦、奥斯汀、奎因的语言路线。
11. 波普尔：《科学发现的逻辑》；库恩：《科学革命的结构》；拉卡托斯与费耶阿本德。
12. 香农（1948）信息论；维纳（1948）控制论；冯·诺依曼的计算机、博弈与自复制研究。
13. 西蒙的有限理性；科尔莫哥洛夫复杂度、所罗门诺夫归纳与蔡廷算法信息论。
14. 贝塔朗菲、普里高津、霍兰德等系统与复杂性研究；马图拉纳、瓦雷拉的自创生与具身认知。
15. Pearl 的结构因果模型；联结主义、统计学习、深度学习与当代神经—符号混合系统。

**阅读这张谱系的三个限制：**“西方理性”在此是分析性统称，不代表一个同质主体；人物与路线之间常有争论，图中的箭头表示问题继承或结构相似，不必然表示直接影响；历史中的经验、技术、制度与非西方知识交流比任何单张谱系图都更复杂。

04层二 · Sequence

2

诊断序列 v2

认知操作系统原生六步 × 梅多斯修正案 A / B / C ＋ 并行设计模式

  1. 复发类型分类

    跟上系统的节拍；"长期一致的行为模式是回路存在的首要线索"（第7章·第1章）

    熵增型 / 对抗型 / 静态结构型三分不变；静态结构型此后须细分至具体基模——每个基模自带已知的动力学签名与对策，诊断从定性猜测升为半定量比对。

  2. 可证伪因果模型修正案 A · 签名形式化

    模型三问；"模型的价值在于能否反映真实的行为模式"（第2章）；把心智模式展现在阳光下（第7章）

    断言"结构 X → 干预 Y 应得 Z → 不作为复发签名 W"必须以预测的行为曲线形状陈述——振荡周期受延迟结构约束、过冲、漂移各有可辨认的曲线特征。说不出曲线，就还没有诊断，只有叙事。

  3. 杠杆定位与控制力切分修正案 B · 二维化与方向校验

    十二杠杆点（第6章）；"高杠杆效应，但方向错误"×3例（库存·渔业·世界模型）

    原有可控性轴（控制内 / 可影响 / 纯约束）与梅多斯的效力轴（参数…范式）正交，得二维图：可控而低效力的因，不值得耗能动性；不可控而高效力的因（他人的范式），是绕行的约束。行动前增设方向校验——福瑞斯特的发现是人们凭直觉找得到杠杆点、但多半推反；既有的"廉价可逆补丁"恰好兼任符号测试探针。

  4. 资本配置比较修正案 C · 缓冲期权计价

    缓冲器（杠杆点11）；"利息是人类最糟糕的发明之一"（第7章）；JIT 案例（第3章）

    可逆补丁按 NPV 照旧；缓冲与适应力存量（土壤、信任、制度能力）改按期权计价——复发成本经由一个正被侵蚀的存量复利放大，贴现会系统性低估结构修复。目标侵蚀本身就是贴现驱动的陷阱；JIT 是用适应力换效率的定价错误的教科书案例。

  5. 二阶自检：观察者在回路内

    转嫁负担基模（第5章）——本步骤的动力学证明

    干预者接管功能 → 系统自调能力萎缩 → 更依赖干预：Watzlawick"被尝试的解决方案就是问题"在书中有了回路图。检验法同构：恢复系统自身能力后择机抽身＝停掉惯常动作看变化；此步几乎必须借外部框架完成——你很难从自己的框架内部看见把你包含在内的回路。

  6. 元立场：无终结解，只有持续导航

    "未来不可预测但可被想象；系统不可控制但可被设计和重构"（第7章）；拥抱失误；保持谦逊

    对活的动态系统索求终结性是范畴错误，也是复发的发生器。小步、可逆、持续监控、顺势改线——她的"与系统共舞"与框架的持续导航是同一操作面。

  7. 设计模式并行新增

    内在责任；带反馈功能的政策（第7章）；"恰当的杠杆点需从一开始就被设计好"（第6章）

    当你在建系统而非修系统：内在责任——让决策者直接承受决策后果（取水口设在自家排水口下游）；带反馈功能的政策＝调整回路的回路（蒙特利尔议定书）；此即元适应力——修复回路的回路，与知识库 V1 / V2 / V3 校验器架构同构。

图谱现有 96 系统 · 842 张力为描述性记录；八基模携带"动力学签名＋对策"，是图谱中可被系统动力学类型化子集的规范性升级——张力仍是演化引擎，但这八种张力有了可计算的形状与已验证的解法。入谱规则：每次套用须附该基模预测的行为签名与可证伪点，否则退回描述层。此规则来自译者自己的警告——初学者用基模最易"削足适履"。
XII·1

政策阻力Policy Resistance

杠杆 3 · 目标第 5 章
多主体各自的目标↔同一存量的现实
回路结构
多条对抗性调节回路（B×n）互相抵消，棘轮式加码。
动力学签名
存量僵持于无人满意的水平；任一方加力，他方等量反制；松手即反弹（罗马尼亚人口政策的悲剧路径）。
对策 → 杠杆
放弃单边压制；协调出更大的总体目标，把维持僵局的能量转向共同方向——瑞典人口政策：目标从数量改写为"每个孩子都被渴望"。
XII·2

公地悲剧Tragedy of the Commons

杠杆 6 · 信息流 / 5 · 规则第 5 章
个体的直接收益↔全体分担的侵蚀成本
回路结构
使用者增长的 R ＋ 缺失或迟滞的资源状态反馈 B。价格不是那条缺失的反馈——稀缺推高价格反而加速最后的攫取。
动力学签名
资源先缓后急地被指数侵蚀，越过再生临界点后崩溃；逼近约束的时间"出乎意料地短"。
对策 → 杠杆
恢复缺失反馈——教育劝诫 / 私有化 / 达成共识、强制执行（红绿灯、计时收费、按量计费）。核心是把使用与后果重新接线。

杠杆 3 · 目标第 5 章
绝对标准↔被坏消息锚定的感知绩效
回路结构
调节回路 B 被一个向下漂移的 R 掩盖：感知↓ → 目标↓ → 努力↓ → 绩效↓。
动力学签名

竞争升级Escalation

回路结构
"以眼还眼"的 R——双方目标互为参照，皆为相对量而非绝对量。

07分歧与防火墙

三处隔离带

Divergences & Firewalls

I本体论承诺的重量 —— 唯一实质分歧

第 4 章宣告一切皆模型，但全书的工作姿态把"结构产生行为、行为是内生的"当作关于世界的断言。框架的裁决：内生性是边界选择的函数——云画在哪里，决定了什么算内生。她承认边界人为，却未把这个承认贯彻回去。

操作性实在论留在层一（任何建模者都需要它），但一切强断言加"相对于该边界"标注，登记于层〇。

II范式超越处的滑坡

"没有任何范式正确 → 任何合适的手段皆可"按字面是工具主义放任，与她自己第 7 章"不要降低善的标准"直接冲突。悬置处理得更干净：拒绝绝对化任何框架是关于认识论保证的判断，不产生实践许可。

删除该句；"空"由佛教语域译入逻辑语域——范式的元意识＋不执著——后方可入层三。

III译本贴标

邱昭良导读将系统思考定性为"整体论哲学＋辩证唯物主义分析方法"，是译者的本土化贴标，非梅多斯立场——她本人更近实用主义可错论＋佛教色彩的谦逊。反黑格尔的框架不应从导读继承此标签。

引用时严格区分正文与导读；导读的另一贡献（基模易被"削足适履"的警告）则被采纳为入谱规则。

    证据强度有限。1993 年成书，论证以轶事＋模拟为主；Urban Dynamics 的住房补贴结论在城市经济学界有争议，世界模型的预测记录是长期论战对象。作为结构直觉的来源可靠，作为经验证据不可靠。

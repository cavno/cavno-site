# Cavno 自动封面 v2 · 增量更新

基于 2026-08-28 提供的最新版 cavno-site.rar 制作。只调整封面体系，不迁移网址、不更改文章正文、不替换站点架构。

## 审查结论

1. 原背景色由图形类型决定，并叠加标题哈希的色相浮动。同一个哲学栏目会因为命中 philosophy、math、city、system 而出现紫、蓝、绿等不同色调。
2. 原规则按顺序返回首个关键词命中结果；例如哲学“地图”可能被识别成城市。正文只间接参与摘要推断，具体标题语义没有充分区分。
3. 原哲学图形为两组圆环和圆点，形成重复的“眼睛”。五个变体主要是轻微旋转、平移或缩放，不是新的构图。
4. 首页搜索独立拼接封面样式与节点，容易与栏目卡片更新不同步。

## 新方案

- **二级栏目决定配色**：固定色相、饱和度及纸面明度规则，不再按标题或图形跳色。哲学统一为低饱和靛灰色；思考、书籍、数学等各有固定色系。首页混合不同栏目时保留各栏目的身份色。
- **内容决定图形**：标题、标签、摘要、正文小标题与正文片段分层加权；具体概念优先于宽泛领域词，标题权重高于正文中的偶然提及。
- **网址决定稳定版式**：网址生成稳定种子，组合 4 类构图、6 类底纹、3 类结构变体；改变排序或重新构建不会随机换图。
- **增加 18 类结构图**：谱系、时间线、递归、公理推演、矩阵、中介桥、分层、反馈、平衡、地平线、因果链、裂隙、网络、保护边界、路线、分布、收益曲线、漏斗。移除旧哲学“眼睛”。
- **共用渲染规则**：首页、一级/二级栏目卡片与搜索缩略图统一使用同一类名和配色函数；搜索索引升至 v2，同时提供旧 v1 索引的显示兜底。
- **文字职责保持不变**：封面只展示标题；摘要与栏目、日期位于下方。列表模式继续显示原有标题。搜索缩略图删除无实际意义的 CV 编号。

这是一套内容驱动的 CSS 规则插画系统，不是每篇文章单独生成的位图。不会增加外部图片、图片接口、字体或新的包依赖。

## 应用方法

1. 备份上面 5 个待覆盖文件。
2. 将增量包的 src、scripts、docs 目录合并到网站源码根目录，保留相对路径并覆盖同名文件。
3. 按原项目流程运行 npm run build，再发布完整构建结果。此包是源码增量，不能把 src 目录直接当成静态网站上传。
4. 可额外运行 node scripts/audit-covers.mjs --built 检查生成后的所有卡片与搜索索引。

无需删除旧页面或逐篇修改 Markdown。package.json、package-lock.json、导航、文章和访问控制配置均未改动。

回退时还原备份的 5 个文件，再移除本次新增的 4 个文件并重新构建即可。

## 后续维护

- 栏目色系集中在 src/lib/cover-design.ts 的 CATEGORY_PALETTES。
- 具体图形规则集中在 SPECIFIC_RULES；DOMAIN_RULES 仅提供领域兜底。
- 标题含糊时，可在 ARTICLE_COVERS 中按完整网址手动指定 motif 和可选 layout。这里故意不开放单篇配色，避免破坏栏目统一性。
- 新增条目后运行 node scripts/audit-covers.mjs。若出现同栏完全重复组合，报告会列出标题；优先完善语义规则或为该条目指定合适图形，而不是随机换颜色。

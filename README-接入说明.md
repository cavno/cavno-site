# 乔布斯的一生 · Cavno 增量代码

## 接入方法

将压缩包中的 `src/` 和 `public/` 两个文件夹合并到现有 `cavno-site/` 项目根目录。
所有文件都是本篇新增文件，不覆盖已有文件，不包含 `.git`、依赖目录或整站源码。
本包可独立接入原附件源码，也可叠加在之前的马斯克、李小龙增量之后。

新增内容为 4 个源码文件及 17 个原文图片/图标文件：

```
src/pages/reading/thinking/steve-jobs-system-evolution.astro
src/legacy/reading/thinking/steve-jobs-system-evolution/body.html
src/legacy/reading/thinking/steve-jobs-system-evolution/style.css
src/content/items/reading-thinking-steve-jobs-system-evolution.md
public/apps/reading/thinking/steve-jobs-system-evolution/images/*
```

请同时合并 `public/`，否则文章中的原图会无法显示。

在原项目根目录执行原有构建命令：

```sh
npm run build
```

随后按项目原有方式提交、推送并发布。新页面路径为：

```
/reading/thinking/steve-jobs-system-evolution/
```

现有内容集合会自动把条目加入 Thinking 栏目、Reading 总列表、首页和全站搜索。
无需修改栏目页、公共导航、搜索脚本或此前文章。
请重新构建整站；`body.html` 是 Astro 使用的正文片段，不应单独上传为完整页面。

## 原文保留

- 使用文档原有标题，保留全部 13 个主章节、原有次级标题、文字顺序、分段、加粗与斜体。
- 保留全部 5 张表格，83 处公式仅作显示排版，原始表达式保留于 `data-source` 属性中。
- 保留原文 17 个图片/图标文件，文件内容逐字节一致，30 处图片引用顺序一致。
- 保留原文来源名称、`+1`/`+2` 等来源标记；原文唯一实际超链接的文字及地址均保留。
- 没有为来源标记补造链接，没有改写、补写人物论述或新增结论。
- 网页列表摘要直接取原文“乔布斯的传奇不在于……”这一段，标签取自原文概念。
- 条目日期为本次入站日期 2026-10-21。

图片只调整显示尺寸、留白和响应式布局，没有裁剪或重新生成。
原文连续的三张图片在桌面并排展示，手机按原顺序纵向展示。
原文的来源图标和相邻来源文字合并为紧凑来源标记，文字顺序保持一致。

## 页面设计

沿用原站 `Base.astro`、全站导航、页脚、搜索、字体与颜色变量。
新增样式限定于 `jobs-` 类名，不影响其他文章。
提供侧边目录、手机折叠目录、章节锚点、栏目返回和顶部返回。
长公式与宽表格在自身区域内横向滚动，不撑宽整页。

数学公式已静态编译为 MathML，不需要新增项目依赖或在线数学渲染脚本。
浏览器需支持原生 MathML，本次已在 Chromium 浏览器中验证。

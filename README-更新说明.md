# 基督教思想发展史页面增量包

本包仅包含新增页面所需的 4 个源码文件，不含网站其他源码，也不会删除或移动现有内容。

新增地址：`/reading/theology/christian-thought-systems-history/`

## 更新方法

将包内 `src` 文件夹合并到 Cavno 源码根目录的 `src` 文件夹，然后在项目根目录执行：

```powershell
npm run build
```

构建成功后，按网站原有发布流程上传新的构建结果。本包没有自动修改线上网站。

## 包含内容

- Theology 栏目下的文章路由页；
- Explore、Reading 和 Theology 目录页自动读取的文章记录；
- 从附件提取并完整保留的 15 章正文；
- 与站点外壳兼容的隔离样式，包括桌面固定目录、移动端横向章节导航、表格与公式局部滚动。

# Cavno 概念库增量更新

新增路径：`/about/concepts/`。发布后从桌面导航和移动端菜单的 About → 概念库进入。

## 更新内容

- 首批 22 个概念，分为系统与演化、逻辑与认知、投资与市场、AI 与实践四组。
- 每条包含定义、关键要点、适用边界与常见误解、示例、站内延伸阅读及关联概念；部分词条附外部定义参考。
- 支持中文、英文、缩写和正文关键词搜索、领域筛选、空结果提示及重置。
- 每个词条有独立锚点。全站搜索可以直接定位词条；点击关联概念时会自动解除阻挡目标的筛选条件。
- 页面沿用站内字体、象牙白背景、墨黑文字与珊瑚色强调；窄屏采用单栏排版，完整定义直接展开。
- 无 JavaScript 时仍显示全部词条和阅读链接。

## 覆盖方式

此包基于当前工作源码（含上一版图标与兼容性更新），仅包含本次改动的七个文件。先备份同名文件，再把包内 `src`、`scripts`、`public` 合并覆盖到源码根目录，运行项目原有的 `npm run build`，按原方式部署生成的 `dist`。这是源码增量包，不是直接覆盖线上静态文件的整站包。

文件清单：

1. `src/content/concepts.ts`：词条与分组数据。
2. `src/content/nav.json`：About 导航数据。
3. `src/layouts/Base.astro`：桌面下拉与移动端入口。
4. `src/pages/about/concepts.astro`：概念库页面与筛选交互。
5. `src/pages/search-index.json.ts`：概念加入全站搜索。
6. `scripts/gen-shell.mjs`：旧页面导航生成器增加 About 入口。
7. `public/shell.js`：生成后的旧页面导航。

## 后续维护

在 `src/content/concepts.ts` 的 `concepts` 数组中补充词条，并更新 `conceptUpdated`。每个 slug 必须唯一；`article` 填写站内已有文章路径，`related` 引用已有概念 slug。新增词条会自动进入分组、页内索引及全站搜索。构建时会检查重复 slug、关联概念和文章路径。

本期为首批基础概念库，未声称覆盖站内所有术语；后续可沿同一结构扩充专业分支。
